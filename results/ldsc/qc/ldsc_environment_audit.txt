AUTHORITATIVE ASTHMA INPUT
- Proposed source: results/gwama/asthma_meta.out.gz.
- It is the current corrected 12-study GWAMA 2.1 output and contains 34,316,972 variants (plus header), as recorded independently in current mapping and heterogeneity summaries.
- Current scripts describe this as the fixed-effect analysis; the current GWAMA log lists 12 input studies and confirms completion.
- The corrected GRCh38-lifted Shrine input is included in config/gwama_input/gwama.in; current scripts 09 and 12 explicitly state that the output follows the corrected Shrine rerun.
- Header: rs_number, reference_allele, other_allele, eaf, beta, se, beta_95L, beta_95U, z, p-value, _-log10_p-value, q_statistic, q_p-value, i2, n_studies, n_samples, effects.
- GWAMA output contains no chromosome or position columns.
- reference_allele is the beta-aligned effect allele; this was confirmed previously by the current scripts 02/05 data flow and direct input/output checking documented in results/mr/finngen/exposure/asthma_exposure_5254_qc.txt.
- beta and se can form Z=beta/se; the output also provides z directly.
- eaf and n_samples are unusable (-9 in audited/current output use). scripts/05_prepare_gwama_inputs.R passed only MARKERNAME, EA, NEA, BETA and SE to GWAMA, discarding even the N values available in some harmonised sources.
- Marker identifiers are mixed: many rsIDs, but some coordinate/allele or other identifiers. At p<=5e-9, the current mapping audit matched 37,669/39,933 evaluated variants to rsIDs (94.33%), illustrating that rsID coverage is incomplete.
- Genome build is not uniformly established: although inputs were assembled under data/final_hg38, five contributing files show BUILD=unknown (495_PheCode, HanY, asthma_DISCOVERY, UKBB.asthma-2, and ukb.allasthma). Coordinate-style identifiers from unknown-build files must not be assumed GRCh38.
- Conclusion: authoritative current asthma association result, but not yet LDSC-ready.

ASTHMA SAMPLE SIZE AND ANCESTRY
- No usable per-variant or constant meta-analysis N is present in the GWAMA output.
- Some upstream files contain N: 495_PheCode and asthma_DISCOVERY have per-variant N, GCST90029018 has n, and HanY has N. Other contributing files were assigned N=NA.
- The 495_PheCode input demonstrably has varying per-variant N; therefore a simple constant across all source data is not supported.
- No locally documented, overlap-aware total cases/controls for the 12-study asthma meta-analysis was found.
- Summing study N or cases/controls would not be valid without resolving participant/cohort overlap and compatible phenotype definitions; several inputs are UK Biobank-derived and may overlap.
- The combined asthma ancestry composition is not documented by local project metadata. The use of a European 1000 Genomes panel for PLINK clumping does not prove that every asthma study is European-only.
- Required before munging: a defensible LDSC N strategy (ideally per-variant effective N or an overlap-aware trait-level effective N), cases/controls and effective-N convention for the binary phenotype, plus documented ancestry composition.

ANCESTRY/REFERENCE WARNINGS
- FinnGen is a Finnish cohort/genetic isolate. No detailed ancestry-composition metadata file accompanies the local downloads.
- Standard European 1000 Genomes LD scores are broadly ancestry-related but are not Finnish-specific; LD/frequency differences may affect LDSC fit and should be acknowledged and checked.
- The asthma meta-analysis ancestry is locally unresolved. Standard European LD scores are inappropriate if materially multi-ancestry summary statistics are present without a justified ancestry-specific strategy.
